# v0.8.1

- 所有功能升级为单窗口图形工作流：连接表单、登录方式、域名/邮箱、确认、菜单选择、实时日志、结果与停止控制均留在 WPF 客户端内。
- 不再启动外部控制台窗口；内嵌 Go 引擎通过重定向流与 GUI 交互，功能编号 `[1]`—`[15]`、`[K]` 保持不变。
- SSH 初始密码使用遮罩弹窗和每次操作随机生成的本机命名管道交给专用 AskPass helper；密码不进入命令行参数、普通 stdin、日志、剪贴板或磁盘。
- 非 root 用户的 sudo 密码提示自动切换为 GUI PasswordBox；普通输入继续使用图形输入框和 Y/N/直接回车快捷按钮。
- 新增安全停止与二次确认的强制结束分支；运行中的工作流会阻止误关主窗口。
- GUI EXE 同时内嵌并校验工作流引擎、AskPass helper 与 XAML，继续保持单文件分发。
