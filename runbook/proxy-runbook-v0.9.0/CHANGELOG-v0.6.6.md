# v0.6.6

- 修复同一轮施工中重复申请 3x-ui API Token，导致持久化 OpenAI/ChatGPT → WARP 路由无法取得 API 上下文的问题。
- API 上下文现在按环境、root-only 缓存、交接单、安装结果的顺序读取，并对每个候选执行 localhost API 实测。
- 只有全部已有 Token 缺失或失效时才调用一次 Token 生成命令；生成结果立即验证并缓存。
- 面板凭据轮换与交接单导出复用统一 API 上下文，不再无条件制造新 Token。
- Bearer Token 通过文件描述符传给 `curl`，避免出现在进程命令行参数中。
- WARP 持久路由在现有出站与规则完全匹配时直接成功退出，不重复备份、保存或重启 Xray。
- 新增隔离回归测试，覆盖 Token 复用、失效回退、最后生成与缓存复用。
- 保留 v0.6.5 的远端版本状态机、安全升级、防降级、同版禁止重装及菜单 `[13]` 安全卸载规则。
