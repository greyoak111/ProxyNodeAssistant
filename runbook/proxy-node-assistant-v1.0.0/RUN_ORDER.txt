ProxyNodeAssistant v1.0.0 重置线 — 最短顺序

1. 运行 ProxyNodeAssistant-v1.0.0-win64.exe（或完整解压便携包）；菜单 [1] 是唯一安装/升级/线路施工入口
2. 在菜单 [1] 的二级菜单明确选：临时密码会话，或节点专属长期 SSH key
3. 每次手输本次 VPS IP/hostname；不会暗中复用上次 VPS
4. 手输 SSH user
5. SSH port 默认 22，可回车
6. EXE 显示 SSH Host 指纹；核对后在 EXE 自己的 [y/N] 提示输入 y
7. 临时模式：只向 OpenSSH 输入密码；一次性 key 不显示，操作结束前自动撤销和删除
8. 长期模式：Windows 生成/复用每节点独立 Ed25519 SSH key，并显示真实 Private/Public Key
9. 图形版在遮罩密码框中输入 VPS 密码，并通过当前用户专用随机命名管道交给 OpenSSH
10. 所选模式完成实际 SSH_KEY_OK 验证
11. 菜单 [1] 先识别版本：同版跳过、旧版升级、远端新版则停止并提示更换 EXE
12. VPS 自动判断 FRESH / EXISTING；已有节点才显示 [0] 保持现有线路
13. 必须明确选择线路：[1] 灰云直连 / [2] 橙云 CDN / [3] 双路；不能用空回车代替
14. 按所选线路分别手输灰云、橙云域名与证书邮箱；双路必须是两个不同主机名
15. 明确选择伪装模板、性能档与 WARP 策略；变更前备份不可关闭
16. 程序显示完整施工计划；只有输入大写 APPLY 才开始上传和修改，其他输入无副作用取消
17. Reality 24443 与 CDN/XHTTP 8443 都必须把链接导入真实客户端并实际浏览，不能虚假确认
18. 全链路成功后才允许整理旧备份、复制交接单或打开面板隧道

后续性能与流量：
  [16] 检测 / 自动 / 低配 / 标准 / 高配 / 回滚
  [17] SSH/vnStat 估算（VPS 口径）
  [T]  KiwiVM/条件式服务商 API（Windows 本地，不登录 VPS）

兼容说明：EXE 使用一套通过启动验证的 Windows OpenSSH，并对 Host Key 执行严格解析和有限重试。OpenSSH 不再弹出自己的 Host Key yes/no；Host 指纹由 EXE 显示、确认并固定到节点专用 known_hosts。密码仍只交给 SSH 认证，不写日志或历史。
